# Юпитер Авто — статика для блоков Битрикс24

Два файла, которые подключаются к собственным блокам Битрикс24.Сайты
через `assets` в манифесте блока.

| Файл | Что это |
|---|---|
| `jupiter.css` | Дизайн-система. Все правила ограничены обёрткой `[class*="block-repo-"]`, поэтому на страницах без наших блоков ничего не меняют. |
| `jupiter.js` | Интерактив блоков: слайдер, кредитный калькулятор, фильтры каталога, аккордеон, тосты, переключатель тем. Работает только по нашим селекторам. |

Файлы **генерируются** из основного репозитория проекта:

```bash
node bitrix/build-portal-css.mjs
node bitrix/build-portal-js.mjs
```

Руками не править — правки затрутся при следующей сборке.

Репозиторий публичный только потому, что Битрикс24 требует внешний
HTTPS-адрес для `assets`. Никаких данных клиента здесь нет: только
таблица стилей и код интерфейса.
